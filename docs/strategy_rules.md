## 一、通用设置（两套策略共用）

### 1. 数据

| 项目 | 规则 | 说明 |
|---|---|---|
| 交易品种 | XAUUSD | |
| 数据来源 | Dukascopy | |
| 价格类型 | Bid | 点差在执行层另外扣除 |
| K线周期 | 2 小时 | 由 Dukascopy 的 1 小时数据合成。理由：__熟悉两小时__ |
| 2 小时K线切分 | 每根从 UTC 偶数整点开始（00:00、02:00、04:00……22:00） | 与 TradingView 对比时需确认其切法一致 |
| 时区 | UTC | 避免夏令时造成的时间重复或缺口 |
| 回测总区间 | 2015-01-01 00:00 UTC 至 2025-12-31 23:59 UTC | 覆盖上涨、下跌、震荡等不同行情 |
| 样本内区间（开发和观察） | 2015-01-01 00:00 UTC 至 2021-12-31 23:59 UTC | 约占总区间 64% |
| 样本外区间（最终测试前不看） | 2022-01-01 00:00 UTC 至 2025-12-31 23:59 UTC | 规则全部定死后只运行一次 |

### 2. 指标

| 项目 | 规则 | 说明 |
|---|---|---|
| MACD 参数（快线 / 慢线 / 信号线） | 12 / 26 / 9 | |
| 计算 MACD 用的价格 | 收盘价 | |
| 预热期 | 开头 100 根K线只计算指标，不交易 | 保证均线稳定 |

### 3. 信号与成交

| 项目 | 规则 | 说明 |
|---|---|---|
| 信号判断依据 | 只用已收盘的K线 | 防未来函数的第一道关 |
| 入场成交价格 | 信号K线的下一根K线开盘价 | 收盘时才知道信号，来不及按收盘价成交 |
| 按信号出场的成交价格 | 信号K线的下一根K线开盘价 | |
| 止损触发判断 | 用K线最高价 / 最低价，盘中碰到即触发 | 当前金叉死叉策略不设止损，此条留给后续使用 |
| 止损成交价格 | 正常按止损价；若开盘价已越过止损价（跳空），按开盘价成交 | 同上 |
| 同一根K线同时碰到止损和止盈 | 按止损处理 | 宁可低估收益 |

### 4. 成本

| 项目 | 规则 | 说明 |
|---|---|---|
| 点差 | 每盎司 0.30 美元 | 需查交易平台黄金的典型点差后确认 |
| 点差扣除方式 | 做多：入场价 = 开盘价 + 点差，出场价 = 开盘价（或止损价）<br>做空：入场价 = 开盘价，出场价 = 开盘价（或止损价）+ 点差 | 数据为 Bid 价，每完成一笔交易付一次点差 |
| 滑点 | 0 | 阶段 5 做敏感性测试（0 / 0.2 / 0.5 美元等） |
| 隔夜利息（swap） | 忽略 | 在最终报告中注明此假设 |

### 5. 资金与仓位

| 项目 | 规则 | 说明 |
|---|---|---|
| 初始资金 | 5000 美元 | |
| 每笔仓位 | 固定 1 盎司 | 不做复利。仓位价值约为资金的一半，收益率百分比偏小，夏普比率不受影响 |
| 同一时间最多持仓 | 1 笔 | |
| 持仓中出现同方向新信号 | 忽略 | |
| 持仓过周末 | 允许 | 周一跳空开盘的影响计入盈亏 |

### 6. 回测起止处理

| 项目 | 规则 |
|---|---|
| 首次入场 | 预热期结束后，等出现第一个金叉或死叉信号才入场 |
| 回测结束时仍有持仓 | 在最后一根K线收盘价强制平仓（做多按收盘价，做空按收盘价 + 点差） |

## 二、MACD 金叉死叉策略（用于验证回测骨架）

### 1. 信号定义

| 项目 | 规则 |
|---|---|
| 金叉 | 上一根K线 DIF <= DEA，且当前K线 DIF > DEA |
| 死叉 | 上一根K线 DIF >= DEA，且当前K线 DIF < DEA |
| 零轴过滤 | 不加 |

### 2. 交易方向

| 项目 | 规则 |
|---|---|
| 金叉时 | 做多 |
| 死叉时 | 做空 |
| 持多单遇到死叉 | 平仓并反手做空 |
| 持空单遇到金叉 | 平仓并反手做多 |

### 3. 风控

| 项目 | 规则 | 说明 |
|---|---|---|
| 止损 | 不设 | 骨架跑通后，可临时加固定止损，专门验证执行层的止损代码 |
| 止盈 | 不设，靠反向信号出场 | |
